## 镜像为什么变小

原镜像 52,046,497,042 bytes，精简后 24,516,690,303 bytes，减少 27,529,806,739 bytes，约 52.9%。Docker 展示的未压缩镜像大小不是实际网络传输量。

旧基础镜像的一层约 24.2 GB，包含旧模型和旧 AI 工作树。随后删除旧目录仅在新层遮蔽这些文件，不会从父层移除其数据；其他历史层也保留了被覆盖或删除的文件。当前有效模型自身约 11.2 GB，不能作为旧缓存删除。

`docker/Dockerfile.release` 将最终运行文件系统与五个大模型文件分别复制到六个独立镜像层，舍弃不可见历史层。五个模型文件内容保留，支持并行上传、失败重试和后续复用。当前模型、依赖、应用程序均保留，不进行量化、不卸载 PyTorch/CUDA/ROS。环境变量按键值核对一致，USER、WORKDIR、ENTRYPOINT、CMD 等运行配置保留；仅将过时的 active-system 标签更新为 rebuild。体积与配置记录见 `evaluation/expanded_20260915/release_slim_packaging.json`。

在已经具备 V7 本地镜像的开发机上重建发布镜像：

```bash
docker build -t docker_ai_module:research-20260916-v7-slim - < ai_module/docker/Dockerfile.release
```

空构建上下文避免再次向 Docker daemon 传输 11.2 GB 的模型目录。原 V7 镜像可以用本仓库 `docker/Dockerfile` 构建；模型准备参见 `MODEL_ASSETS.md`。
